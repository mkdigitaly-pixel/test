# Анализ целевой аудитории mkekspert.ru

Цель — понять **кто** приходит, **зачем** (Jobs to be Done) и **как** с ними говорить в контенте.

## Структура папки

```
audience/
├── README.md              — этот файл
├── jtbd-map.md            — карта Jobs to be Done (сегменты × работы)
├── segments.md            — портреты сегментов аудитории
├── content-strategy.md    — контент-стратегия под каждый сегмент
└── research/              — сырые данные (интервью, Метрика, отзывы)
```

## Что такое Jobs to be Done

Люди "нанимают" продукт/услугу, чтобы выполнить **работу** — решить проблему в конкретном контексте.

Формат: *"Когда [ситуация], я хочу [мотивация], чтобы [результат]"*

## Как работать с этой папкой

1. Заполни `jtbd-map.md` — опиши ключевые "работы" клиентов
2. Уточни портреты в `segments.md`
3. На основе JTBD выстрой контент-план в `content-strategy.md`
4. Складывай исходники в `research/`
