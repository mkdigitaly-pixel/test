# Исправление всплывающего окна, 23 ноября 2026

Мария сообщила о регулярно появляющемся окне Windows/System32. В действии единственного пользовательского задания mkekspert-content обнаружен прямой запуск powershell.exe каждые пять минут. Параметр WindowStyle Hidden применялся внутри уже запущенного консольного процесса, поэтому такое окно могло кратко появляться до скрытия.

Действие того же задания заменено на имеющийся pythonw.exe с automation/run_windowless.py. Скрытое состояние задается при создании дочернего PowerShell, а не после его запуска. Потомки наследуют скрытую консоль. Выходной код сохраняется для повторов при ошибке; обычный журнал публикаций остается прежним, ошибки внешнего запуска записываются в logs/launcher-errors.log.

Все 40 проверок прошли: 38 прежних и две реальные проверки Windows-процессов. Проверены невидимость консоли родителя и потомка, наследование консоли через PowerShell, пути с пробелами и кириллицей, сохранение ненулевого кода завершения. Тесты не отправляют посты и не меняют рабочую очередь. При исправлении тестового сценария учтено чтение UTF-8 с BOM в Windows PowerShell 5.1.

Параметры расписания, текущая учетная запись, проверка сети, три повтора сбоя, блокировки от дублей и выключатель публикаций сохранены. Второго задания нет. Прежнее действие сохранено в закрытом XML для возврата. Установщик и инструкции обновлены, чтобы восстановление не возвращало прежний способ запуска.

Первоисточники: [STARTUPINFO Windows](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/ns-processthreadsapi-startupinfow), [наследование консоли](https://learn.microsoft.com/en-us/windows/console/creation-of-a-console).
