# SEO-контент-план: Дзен (klientyandtrafik)

**Цель:** органический трафик из поиска Яндекса и ленты Дзена → заявки на [razbor-direct](https://mkekspert.ru/razbor-direct)  
**Ниша:** Яндекс Директ, B2B, малый бизнес с бюджетом  
**Ритм:** **2 статьи в неделю** (старт), далее 1–2 по результатам  
**Связанные файлы:** `references/dzen-markup.md`, `references/brand.md`, `briefs/`, `queue/publish-queue.yaml`

## Как работает SEO на Дзене

| Канал трафика | Что влияет |
|---------------|------------|
| **Поиск Яндекса** | Заголовок (H1), структура H2/H3, ключ в первых абзацах, дочитываемость, уникальность |
| **Лента Дзена** | CTR обложки, крючок, удержание, регулярность |
| **Рекомендации** | Серия статей по одной теме, внутренние ссылки между материалами |

**Принцип:** одна статья = один главный ключ + 3–7 LSI. Заголовок с ключом или болью ЦА, лид отвечает на запрос за 5 секунд.

## 4 столпа контента (кластеры)

```
                    ┌──────────────────────┐
                    │  P1 Диагностика      │  «почему не работает»
                    │  ошибки, слив, нет   │
                    │  заявок, аудит       │
                    └──────────┬───────────┘
                               │
     ┌─────────────────────────┼─────────────────────────┐
     ▼                         ▼                         ▼
┌─────────────┐        ┌─────────────┐        ┌─────────────┐
│ P2 Кейсы    │        │ P3 Коммерция│        │ P4 Инструм. │
│ цифры B2B   │        │ услуга,     │        │ Метрика,    │
│ ниши        │        │ цена, выбор │        │ ЕПК, РСЯ    │
└─────────────┘        └─────────────┘        └─────────────┘
```

| Столп | Задача SEO | Тип статей | CTA |
|-------|------------|------------|-----|
| **P1 Диагностика** | широкий охват, верх воронки | гайды, чек-листы, «ошибки» | razbor-direct |
| **P2 Кейсы** | коммерческий + доверие | кейс с цифрами до/после | razbor-direct |
| **P3 Коммерция** | «заказать / цена / выбрать» | экспертный обзор + прайс | razbor-direct / услуга |
| **P4 Инструменты** | узкие запросы, экспертность | how-to по Метрике, ЕПК, РСЯ | razbor-direct |

**Приоритет запуска:** P1 → P2 → P4 → P3 (кейсы конвертят лучше всего, но P1 даёт объём).

## Шаблон заголовка под SEO (Дзен)

Формулы (выбрать одну на статью):

1. **Кейс:** `{метрика} с {было} до {стало}: кейс {ниша} в Яндекс Директе`
2. **Боль:** `{симптом}: что проверяю в кабинете в первую очередь`
3. **How-to:** `Как {действие} в Яндекс Директе: пошагово для B2B`
4. **Сравнение:** `{A} или {B} в Директе: что выбрать для {ниша}`
5. **Коммерция:** `Сколько стоит {услуга}: из чего складывается цена`

Правила: до **100 символов** (цель), макс. 140; ключ ближе к началу; цифра или ниша; без кликбейта.  
Разметка: `references/dzen-markup.md`.

## Структура SEO-статьи (чеклист)

Перед написанием — бриф в `briefs/YYYY-MM-DD-{id}.md`:

```yaml
main_keyword: ""
lsi: []
intent: info | commercial | case
competitors_gap: ""   # что не закрыли топ-5 Яндекса
utm_campaign: ""
```

Тело статьи:

1. **Крючок** — ключ или боль в 1-м абзаце
2. **Контекст** — для кого, ниша, бюджет
3. **H2** — подзапросы (3–6 блоков)
4. **Цифры** — таблица было/стало (для кейса обязательно)
5. **FAQ** — 3–5 вопросов (хвосты НЧ, AEO)
6. **CTA** — один блок razbor-direct + TG

Объём: **3500–7000 знаков** (кейс ближе к 5000–7000, гайд 3500–5000).

## Workflow: от идеи до публикации

```
idea → brief (briefs/) → draft (articles/dzen/articles/) → 👤 approve
  → queue approve → publish dzen → dzen_url → publish teasers
```

| Шаг | Кто | Файл / команда |
|-----|-----|----------------|
| 1. Бриф + ключи | Агент | `briefs/` |
| 2. Черновик статьи | Агент | `articles/dzen/articles/` |
| 3. Обложка | Агент ТЗ / 👤 Canva | `assets/covers/{id}.jpg` |
| 4. Тизеры TG + VK | Агент | `dzen/teasers/tg/`, `dzen/teasers/vk/` |
| 5. Согласование | 👤 | `ок {id}` |
| 6. Очередь | Агент | `queue/publish-queue.yaml` |
| 7. Публикация | 👤 или бот | `publish dzen {id}` |
| 8. Тизеры | бот | `publish teasers {id}` |

## Что не публикуем на Дзене (чтобы не размывать SEO)

- Курс «подписчики в TG» — отдельный лендинг, отдельная рубрика (если нужна — другой канал)
- Чистый копипаст с VC без переструктурирования
- Статьи без главного ключа и интента
- Несколько CTA в конце (только razbor-direct + TG)
