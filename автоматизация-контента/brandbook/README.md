# Brandbook mkekspert

Цель брендбука — чтобы **цвета, акценты и обложки** для:
- Дзен (RSS + HTML)
- VK
- TG
- блог на `blog.mkekspert.ru`

выглядели **единым образом** и задавались из одного места (tokens).

## Что смотреть дальше
- `colors.md` — палитра (primary/secondary) и правила применения
- `covers.md` — как применять цвета в обложках
- `tokens.json` — машинный источник правды для кода
