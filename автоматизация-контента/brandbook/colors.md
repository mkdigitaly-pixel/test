# Цветовое решение (единая палитра)

> Источник правды: `tokens.json`

## Neutrals (фон/текст)
- **Фон (Primary bg):** `#181818`
- **Глубокий фон (bgDeep):** `#151515`
- **Текст:** `#FFFFFF`
- **Нейтральные подписи/серые:** `#B0B0B0`

## Акценты (Primary accents)
- **Зелёный акцент (brandGreen):** `#4EAF4E`
  - для кнопок/рамок/ключевых линий
- **Жёлтый акцент (brandYellow):** `#FFCC4A`
  - для акцентов “тепла”: точки, акценты на линиях, декоративные элементы

## Secondary / Alternative (для “теплого минимализма”)
- **Терракота:** `#A85A32`
- **Тёплый песок:** `#D4A373`
- **Молочный беж:** `#F5D6C6`
- **Золотистый:** `#D4AF37`
- **Уголь (для глубоких теней):** `#3D3D3D`

### Как трактовать “единое”
- Основной стиль (по умолчанию) — **Primary** набор.
- Secondary допускается как вариация фона/подложки для “минималистичных” серий, но с теми же пропорциями акцентов (зелёный/жёлтый) в композиции.
