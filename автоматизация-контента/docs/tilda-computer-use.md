# Tilda через Browser / Computer Use

Архитектура, которую используем для правок **mkekspert.ru** (сайт остаётся на Tilda):

```
Cursor
  ↓
AI-агент
  ↓
Browser / Computer Use  (залогиненная сессия Tilda)
  ↓
Tilda Editor (tilda.cc)
```

Официальный API Tilda — **только чтение**. Писать в редактор можно только через UI (руками или Computer Use).

Готовые макеты по-прежнему лежат в `content/tilda-*.html` — агент вставляет их в блоки T123 / правит тексты в Zero Block по этим правилам.

---

## Политика действий агента

### Можно без спроса

| Действие | Пример |
|----------|--------|
| ✓ Редактировать страницы | открыть `/razbor-direct`, править блоки |
| ✓ Менять тексты | заголовки, абзацы, кнопки |
| ✓ Менять изображения | обложки, картинки в блоках |
| ✓ Добавлять / удалять блоки | T123 HTML, Zero, секции контента |
| ✓ Сохранять | Save / сохранить страницу в редакторе |

### Только после явного «да» в чате

| Действие | Почему |
|----------|--------|
| ⚠ Публикация (Publish) | сайт сразу видят люди |
| ⚠ Удаление страницы | необратимо |
| ⚠ Изменение домена / DNS | риск отвала сайта |
| ⚠ SEO-настройки страницы/сайта | title, description, robots, sitemap, аналитика в настройках |

Если задача звучит как «опубликуй» / «залей на прод» — сначала коротко спросить подтверждение, даже если раньше уже публиковали.

### Запрещено

- Менять оплату / тариф / биллинг Tilda
- Передавать логин/пароль в чат повторно (сессия в браузере)
- Править чужие проекты в аккаунте без указания
- Массово удалять блоки «на всякий случай»

## Что нужно один раз от Марии

1. **Cursor с Computer Use / Browser** (Desktop или среда, где агент видит браузер)
2. В браузере агента — **войти в Tilda** (один раз), сессия сохраняется
3. Открытый проект сайта **mkekspert.ru** (project id `9707577`)
4. Макеты: `content/tilda-razbor-direct.html`, `content/tilda-blog-block.html`

API-ключи в `ДОСТУПЫ.env` — для **проверки** после правок (экспорт HTML), не для записи.

---

## Рабочий цикл задачи

1. Пользователь: «обнови razbor в стиле блога»
2. Агент открывает Tilda → страница `razbor-direct` (page id `146521496`)
3. Вносит правки / вставляет HTML → **Save**
4. Показывает превью / скрин в чат
5. Спрашивает: «публикуем?» → только после «да» жмёт Publish
6. Опционально: API `getpage` / live URL — сверка

---

## Эта среда (Cloud Agent на сервере)

Сейчас у этого cloud-агента **нет** подключённого Browser/Computer Use к твоему экрану.  
Правила и чеклист уже в репо — они сработают, когда запуск идёт в Cursor **с Computer Use** (обычно Desktop / BYO machine с браузером).

Пока Computer Use нет: агент готовит HTML → ты вставляешь, либо запускаешь того же агента локально с браузером.
