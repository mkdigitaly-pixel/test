# Шаблон и SEO блога

Обновление 12.10.2026. Действующий дизайн сохранён: Onest, ivory, терракотовые кнопки, общие шапка и подвал. CSS загружается из `articles/dzen/blog-site/blog-theme.css`; версия ссылки зависит от содержимого файла.

Новые статьи получают Article и BreadcrumbList, ссылки на связанные услуги, один og:type=article и фактическую дату публикации. Для дат используются blog_published_at и опубликованная RSS-лента. Расписание, дата Дзена и дата отправки в соцсети не являются датой публикации в блоге.

Существующие проверенные страницы с корректной датой сохраняются без изменения при обычном деплое. Целенаправленная повторная публикация конкретной статьи сохраняет её первую дату в RSS и в очереди. Для dateModified нужна явно сохранённая blog_modified_at реальной правки. Отсутствующие даты sitemap не подменяются текущим числом.

Файл Google `google2cf8dbb1324d9160.html` находится в BLOG_SITE_DIR и сохраняется при последующих сборках. Поддерживаются пути обложек /covers и /dzen-covers. Страница контактов входит в sitemap.

Approved без фактической публикации не добавляется при пересборке RSS. В текущий блог входят опубликованные статьи и материал, который действительно публикуется в текущем слоте. Рабочее расписание, очереди и настройки доступа этим обновлением не меняются.

Проверка на сервере без отправки материалов:

```text
python3 -m unittest discover -s автоматизация-контента/automation/tests -p 'test_*.py' -v
```

Проверено 17 сценариев, включая действующее расписание и новые SEO-проверки. Материал «Сколько стоит Яндекс Директ для бизнеса» остаётся отдельным локальным черновиком; в расписание и RSS он не добавлен.
