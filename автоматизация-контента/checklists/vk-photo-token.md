# VK: картинка к посту

Ссылка `oauth.vk.com/authorize` для приложения 54768817 **не пускает** (Security Error /
вход от имени сообщества). Её больше не используем.

Ключ сообщества публикует текст, но **не загружает новое фото**. Уже лежащее
на стене фото он прикрепить умеет. Поэтому новый пост с обложкой делаем так:

## Сейчас (без OAuth)

1. Откройте VK **своим профилем Марии** (не переключайтесь на вход «как сообщество»).
2. Скачайте обложку: https://blog.mkekspert.ru/covers/vk-week2-vk.jpg
3. В `klientyandtrafik` создайте запись **от имени сообщества** только с этой картинкой
   (текст можно «обложка» — потом удалим).
4. Откройте фото → «Скопировать ссылку» (вид `https://vk.com/photo-222121025_…`)
   или пришлите ссылку на сам пост `https://vk.com/wall-222121025_…`

Дальше агент публикует **новый** пост с текстом недели и этой фотографией:

```bash
cd automation
python3 publish.py vk-from-post vk-week2 'https://vk.com/photo-222121025_…'
```

Старый пост без картинки (#206) не редактируем.

## Если позже появится пользовательский `VK_USER_TOKEN`

```
VK_ACCESS_TOKEN=ключ сообщества (стена)
VK_GROUP_ID=222121025
VK_USER_TOKEN=пользовательский ключ vk1.a (фото)
```

Тогда обложки грузятся сами. `vk2.a` и ключ сообщества для загрузки не подходят.
