# VK: картинка к посту

**Почему нет фото:** ключ сообщества (`VK_ACCESS_TOKEN`) умеет только **текст** на стене.  
Загрузка фото — только через **пользовательский токен** (`VK_USER_TOKEN`). Это ограничение VK, не баг скрипта.

---

## Быстро: к текущему посту вручную (1 мин)

1. Откройте пост в группе → **Редактировать**
2. **Прикрепить** → фото (обложка из Дзена / TG)
3. Сохранить

---

## Для автопостинга с картинкой

### Шаг 1. Пользовательский токен

1. С компьютера откройте [vkhost.github.io](https://vkhost.github.io/)
2. Права (галочки): **photos**, **wall**, **groups**, **offline**
3. **Разрешить** → скопируйте `access_token` из адресной строки (после `access_token=` до `&`)

### Шаг 2. В `.env`

```
VK_USER_TOKEN=vk1.a.ваш_пользовательский_токен
```

`VK_ACCESS_TOKEN` и `VK_GROUP_ID` — оставить как есть.

### Шаг 3. Проверка

```bash
cd automation
python3 publish.py publish teasers-vk 7-errors-direct --dry-run
```

Должно быть `(текст+фото)`, не предупреждение про VK_USER_TOKEN.

---

## Два токена — зачем

| Переменная | Тип | Для чего |
|------------|-----|----------|
| `VK_ACCESS_TOKEN` | Ключ сообщества | Публикация от имени группы |
| `VK_USER_TOKEN` | Ваш личный (админ) | Загрузка фото на стену |

Токен пользователя храните как пароль. Не публикуйте в открытом доступе.

---

## Если токен утёк

1. [vk.com/settings?act=security](https://vk.com/settings?act=security) → завершить сессии / сменить пароль
2. Получить новый токен на vkhost
3. Ключ сообщества пересоздать в «Работа с API»
