# Яндекс.Метрика — цели для mkekspert.ru

## 1. Подключить счётчик

1. [metrika.yandex.ru](https://metrika.yandex.ru) → Добавить счётчик → `mkekspert.ru`
2. Tilda: Настройки сайта → Аналитика → вставить номер счётчика
3. Опубликовать сайт

## 2. Цели (рекомендуемые)

| Цель | Тип | Как настроить |
|------|-----|----------------|
| **Заявка — форма** | JavaScript-событие или «Отправка формы» | Tilda: после публикации формы — событие `tildaform:` или цель «клик по кнопке отправки» на формах «Записаться», «Заказать аудит» |
| **Клик razbor-direct** | URL содержит `razbor-direct` + клик по кнопке | Цель: посещение страницы `/razbor-direct` |
| **Клик Telegram** | Клик по ссылке | Ссылка `t.me/Mariya1740` или `mariyaprodirect` — цель «клик по внешней ссылке» |
| **Клик телефон** | Клик по `tel:` | Если есть кнопка звонка |

### Простой вариант (минимум)

1. **Цель «Страница razbor-direct»** — тип «Посещение страниц», URL содержит `razbor-direct`
2. **Цель «Спасибо»** — если есть thank-you page после формы (`/thank-you-page` в robots — проверить URL)

## 3. Проверка

- Метрика → Отчёты → в реальном времени — открыть сайт, отправить тестовую заявку
- Убедиться, что цель сработала

## 4. Связка с Директом (когда запустите рекламу на себя)

Директ → цели Метрики → оптимизация на «Заявка» или «razbor-direct»

---

**Время:** ~20–30 минут
