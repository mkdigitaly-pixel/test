# Яндекс.Вебмастер — mkekspert.ru + blog

## 1. Добавить сайты

1. [webmaster.yandex.ru](https://webmaster.yandex.ru)
2. `https://mkekspert.ru` — если ещё нет (метатег уже был на Tilda)
3. **Добавить** `https://blog.mkekspert.ru`
   - подтверждение: HTML-файл или метатег (как для Дзена) — пришлите код агенту, выложит на blog
4. Sitemap:
   - `https://mkekspert.ru/sitemap.xml`
   - `https://blog.mkekspert.ru/sitemap.xml`

## 2. Регион (важно)

Путь: **Представление в поиске → Региональность** → шестерёнка в блоке «Вебмастер».

| Сайт | Какой регион ставить | Почему |
|------|----------------------|--------|
| **mkekspert.ru** | **Россия**, если ведёте клиентов из разных городов / удалённо | Услуга Директ не привязана к одному городу |
| **mkekspert.ru** | **Москва** (или ваш город), если основной фокус — один город и так на сайте | Нужна страница с адресом/городом в контактах |
| **blog.mkekspert.ru** | **Тот же**, что у основного | Блог = тот же бренд, не отдельный бизнес |

**Для модерации** укажите URL страницы с контактами, где видно географию, например:
- `https://mkekspert.ru` (блок контактов), или
- страница с текстом вроде «работаю с клиентами по всей России» / город офиса

Если в Вебмастере уже есть регион из **Яндекс Бизнеса** — он приоритетнее. Тогда править удобнее в [business.yandex.ru](https://business.yandex.ru).

### Что не делать
- Ставить мелкий город «наобум», если на сайте этого нет — отклонят
- Разные регионы у mkekspert и blog без причины
- Путать регион Вебмастера с настройкой Директа (это разное)

## 3. Переобход

Индексирование → Переобход страниц:
- `https://mkekspert.ru/`
- `https://mkekspert.ru/razbor-direct`
- `https://blog.mkekspert.ru/`
- 1–2 статьи блога

## 4. Через несколько дней

- Страницы в поиске
- Региональность — статус заявки
- Поисковые запросы (когда появятся)

**Время:** ~15–20 минут (+ ожидание модерации региона)
