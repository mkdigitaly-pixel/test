# Яндекс.Вебмастер — mkekspert.ru

## 1. Добавить сайт

1. [webmaster.yandex.ru](https://webmaster.yandex.ru) → Добавить сайт → `https://mkekspert.ru`
2. Подтвердить права:
   - **Метатег** в Tilda: Настройки сайта → SEO → дополнительный код в `<head>`
   - или **DNS** / **файл** — как удобнее

## 2. Sitemap (сейчас ошибка 500)

1. Tilda: Настройки сайта → SEO → включить sitemap
2. **Опубликовать** сайт заново (важно)
3. Проверить: открыть https://mkekspert.ru/sitemap.xml в браузере — должен быть XML, не ошибка
4. Вебмастер → Индексирование → Файлы Sitemap → добавить `https://mkekspert.ru/sitemap.xml`

## 3. Переобход

Вебмастер → Индексирование → Переобход страниц → добавить:
- `https://mkekspert.ru/`
- `https://mkekspert.ru/razbor-direct`

## 4. Через 3–7 дней проверить

- Индексирование → Страницы в поиске
- Поисковые запросы (когда появятся показы)

## 5. robots.txt

Уже есть: `https://mkekspert.ru/robots.txt` — sitemap указан. После починки sitemap роботы подхватят карту.
