# Куда писать API

В проводнике слева открой файл:

**`ДОСТУПЫ.env`** (рядом с этим файлом, в папке `автоматизация-контента/`)

Если его не видно:
1. Cursor → Settings → найди `Explorer: Exclude Git Ignore`
2. **Сними галочку** (показывать игнорируемые файлы)
3. Обнови дерево файлов

Либо `Cmd/Ctrl+P` → вставь: `ДОСТУПЫ.env`

Впиши ключи Tilda и напиши в чат: **готово**.
