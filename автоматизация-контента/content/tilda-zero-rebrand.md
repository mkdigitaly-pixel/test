# Tilda Zero — привести mkekspert.ru к брендбуку

Сайт на **Zero-блоках** (T396). Редизайн делаем **поэтапно**: сначала общие настройки и палитра, потом секции главной, потом внутренние страницы.

Превью уже готово: `/razbor-direct` → `content/tilda-razbor-direct.html`  
Блог уже в палитре: `blog.mkekspert.ru`

---

## Быстрая карта цветов (Zero)

| Было на сайте | Роль сейчас | Ставить в Zero |
|---------------|-------------|----------------|
| `#000` / `#111` / `#181818` | тёмный фон | `#F3EBE3` или `#FDFBF7` |
| `#fff` фон секций | светлый | `#FDFBF7` / `#FFFCF8` |
| `#ffcc4a` / `#f5be2e` | жёлтый акцент | **`#A85A32`** (кнопки, бренд) или `#D4AF37` (цифры/премиум) |
| `#4eaf4e` | зелёный | **`#2A6F4C`** |
| `#333` / `#666` текст | серый | **`#3D3D3D`** основной / `#8B6B4A` подписи |
| `#f5f5f5` / `#eee` | серые подложки | `#F3EBE3` / `#F5D6C6` (лёгкий акцент) |

**Не использовать:** синий, мята, бирюза, чёрный фон, фиолетовый.

Шрифты брендбука:

| Роль | Было | Нужно |
|------|------|--------|
| Заголовки | Cabin | **Unbounded** (500/600) |
| Текст | Lato | **Manrope** (400/600/700) |

Google Fonts (вставить в Настройки сайта → HTML-код в `<head>`):

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;600;700&family=Unbounded:wght@500;600&display=swap" rel="stylesheet">
```

Файлы:

## Этапы

### Этап 0 — подготовка (15 мин)

1. В Tilda открыть проект **mkekspert**
2. Сделать **бэкап / дубликат** главной страницы (на случай отката)
3. Держать открытыми: этот файл + превью https://blog.mkekspert.ru/razbor-preview.html

### Этап 1 — «скелет» сайта (общий вид)

Сделать **один раз на весь сайт**:

1. **Favicon** → `assets/brand/favicon-120.png` (или новый `.ico`)
2. Шрифты в `<head>` (блок выше)
3. Вставить CSS из `tilda-zero-global.html` (блок HTML / head) — подтянет фон и базовые цвета там, где Zero не перебивает
4. Фон страницы / Zero-холст: `#F3EBE3`
5. В меню/бургерах: акцентные полоски `#ffcc4a` → `#A85A32`

После этапа 1 сайт ещё «старый» по блокам, но уже тёплый фон и новые шрифты.

### Этап 2 — шапка + первый экран (главная)

Zero-блоки сверху страницы:

1. Меню: фон ivory, ссылки `#3D3D3D` / hover `#A85A32`, CTA-кнопка терракота
2. Hero:
   - убрать чёрный фон
   - H1 / имя бренда: Unbounded, графит + терракота на «Эксперт»
   - кнопка: `#A85A32`, текст белый
   - ссылка кнопки: `#popup:cornerform-zapis-na-vstrechu` или `/razbor-direct`
3. Тексты hero можно взять из [`tilda-hero.md`](tilda-hero.md)

**Готово, когда:** первый экран похож по ощущению на `/razbor-direct` и блог.

### Этап 3 — середина главной

По очереди (каждый блок = один заход 20–40 мин):

| Порядок | Секция на главной | Что менять в Zero |
|---------|-------------------|-------------------|
| 3.1 | Преимущества (налоги / 5 дней / команда) | фоны, иконки/цифры → gold `#D4AF37` или emerald |
| 3.2 | «Давайте знакомиться» / обо мне | карточка на ivory, акценты terra |
| 3.3 | Услуги | карточки `#FFFCF8`, бордер `#E6D9CC`, кнопки terra |
| 3.4 | Кейсы | теги/чипы terra/green, без жёлтого |
| 3.5 | Образование / цифры | big numbers mustard `#D4AF37` |
| 3.6 | Отзывы | фон blush/ivory, без чёрного |

Правило Zero: **не переписывать структуру**, только цвета, шрифты, отступы, кнопки.

### Этап 4 — подвал и формы

1. Футер → тёплый, не чёрный (ориентир: `tilda-footer-contacts-html.html`)
2. Попап формы `cornerform-zapis-na-vstrechu`: поля/кнопка в палитре
3. Проверить все CTA → попап или `/razbor-direct`

### Этап 5 — внутренние страницы

| Страница | Статус |
|----------|--------|
| `/razbor-direct` | HTML готов → вставить/обновить из `tilda-razbor-direct.html` |
| Кейсы (`/rotang`, `/keys-ppu`, …) | после главной, тот же словарь цветов |
| `/portfolio` | как кейсы |
| Политика и служебные | фон + ссылки, без героя |

### Этап 6 — финиш

1. Пройти главную с телефона
2. Вебмастер: переобход `/` и `/razbor-direct`
3. Favicon + title с «МК Эксперт» (см. `checklists/brand-organic-serp.md`)

## Как красить Zero быстрее

В редакторе Zero:

1. Выделить атом (текст / shape / button)
2. Color → вставить hex из таблицы
3. Для кнопок: Background `#A85A32`, Text `#FFFFFF`, Hover Background `#2A6F4C`
4. Для заголовков: Font → Unbounded (если подключена) или ближайший display; иначе оставить Cabin до этапа шрифтов в атомах
5. Shape/линии: `#E6D9CC` или `#D4A373`

Пакетная замена в одном Zero-блоке:

- найти все жёлтые `#ffcc4a` → терракота
- все чёрные подложки → ivory
- все «кислотно-зелёные» `#4eaf4e` → изумруд

## Что делает агент / что вы

| Кто | Что |
|-----|-----|
| **Вы в Tilda** | клики по Zero: цвета, шрифты, Publish |
| **Агент** | чеклисты, CSS-хелпер, HTML готовых секций, тексты, превью |
| **Computer Use (Desktop)** | может кликать Tilda у вас на ПК с подтверждением Publish |

Сейчас следующий практический шаг: **Этап 1** (favicon + fonts + CSS + фон) → затем **Этап 2** (меню + hero).

Напишите «этап 1 сделан» или «делаем героя» — подготовим точечные значения под конкретный Zero-блок (или HTML-замену hero, если проще).
