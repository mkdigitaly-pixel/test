# Главная mkekspert.ru — переписать, сохранив структуру

Вместо покраски десятков Zero-блоков: **один HTML** в палитре брендбука.

Файл: [`tilda-home.html`](tilda-home.html)  
Превью: https://blog.mkekspert.ru/home-preview.html  

## Что сохранено со структурой

| Было | В новом HTML |
|------|----------------|
| Hero / оффер | баннер + анимация |
| Преимущества (команда / налоги / 5 дней) | 3 опоры |
| Обо мне | Мария + факты |
| Услуги | 4 услуги, якорь `#catalog` |
| Цифры опыта | 50+ / 200+ / 10+ / 5+ |
| Кейсы | те же URL, якорь `#portfolio` |
| Образование / сертификаты | 2 колонки |
| Отзывы | 3 отзыва, `#reviews` |
| Прайс | 3 пакета |
| Контакты / CTA | попап `#popup:cornerform-zapis-na-vstrechu` |

## Как вставить в Tilda

1. Откройте **главную** (рабочую, не бэкап)
2. **Скрыть** все старые Zero-блоки контента (или удалить после проверки)  
   Оставить: **меню/шапку** сайта и попап формы
3. Добавить блок **HTML (T123)** → вставить весь `tilda-home.html`
4. Проверить якоря меню: `#about` `#catalog` `#portfolio` `#reviews` `#contacts`  
   (если в шапке другие — поправьте ссылки в меню или в HTML)
5. Publish → https://mkekspert.ru/

## Зачем так

Zero с чёрным/`#ffcc4a` красится атомами часами и ломается. HTML = одна палитра, как у `/razbor-direct` и блога.
