# Moodboard — современный лендинг

Референс: https://pin.it/5b5E8llVj (Pomaii / travel UI)

Что берём:
- светлый фон, много воздуха
- крупный hero с фото + мягкие скругления
- иконки USP в кружках
- карточки с фото (кейсы как «destinations»)
- баннер-оффер (разбор)
- полоса цифр
- CTA-кнопки с заливкой акцента

Палитра остаётся брендбука: ivory / terracotta / emerald / mustard (не оранжевый/бирюза с пина).
