# Визуальный стиль обложек mkekspert

Источники: [mkekspert.ru](https://mkekspert.ru), [VK klientyandtrafik](https://vk.ru/klientyandtrafik).

## Палитра (анализ сайта, август 2026)

| Роль | HEX | Частота на сайте | Где |
|------|-----|------------------|-----|
| Фон тёмный | `#181818` | 182× | кнопки, блоки, hover-основа |
| Фон глубже | `#151515` | 8× | подложки |
| Акцент зелёный | `#4EAF4E` | 100× | CTA, hover кнопок, полосы |
| Акцент жёлтый | `#FFCC4A` | 48× | иконки, выделения |
| Текст основной | `#FFFFFF` | 229× | заголовки на тёмном |
| Текст вторичный | `#B0B0B0` | — | подписи (из дизайна) |
| Серый UI | `#595566` | 60× | вторичный текст сайта |
| Светлая зона | `#F5F5F5` | 20× | светлые секции |

VK-группа использует те же тёмный фон + зелёные акценты в обложках; системные цвета VK (`#3399FF` и т.п.) **не** берём — только бренд mkekspert.

## Стиль обложек (Дзен + TG + VK)

- **Обязательно** на каждый пост: Дзен-статья, тизеры TG/VK, отдельные посты TG/VK
- **Ярко**, контрастно, читается в ленте с телефона
- Тёмный фон + зелёные/жёлтые акценты — как на сайте
- Крупные **цифры** (CPL, %, было→стало) — главный визуальный якорь
- Минимум мелкого текста на картинке (3–7 слов + цифра)
- Без стоковых «улыбающихся людей в офисе»
- B2B: графики, стрелки вниз/вверх, иконки Директа/Метрики — абстрактно
- Полоса слева `#4EAF4E`, снизу `#FFCC4A`, подпись «Мария Ковалева · mkekspert.ru»

## Размеры

| Площадка | Размер | Файл |
|----------|--------|------|
| Дзен, TG-тизер, TG-пост | 1200×630 (16:9) | `assets/covers/{id}.jpg` |
| VK (вертикаль 4:5, без обрезки) | 1080×1350 | `assets/covers/{id}-vk.jpg` |

Для VK при публикации: если есть `{id}-vk.jpg` — используем его, иначе `{id}.jpg`.

## Генерация обложек

**Ключ OpenAI не нужен.** Яркие картинки делает Cloud Agent при подготовке материала (встроенная генерация GPT).

Скрипт `publish.py` перед публикацией проверяет готовые файлы в `assets/covers/`. Если их нет — собирает яркий бренд-шаблон (PIL).

### Порядок приоритета

1. Уже есть `{id}.jpg` / `{id}-vk.jpg` → используем
2. Фон в `assets/covers/_import/{id}.png` → оверлей + текст
3. `OPENAI_API_KEY` в `.env` (опционально, если появится)
4. Авто-шаблон PIL (градиент, график, стрелка — цвета бренда)

### Команды

```bash
cd automation
python3 publish.py cover penoplast-case          # из очереди
python3 publish.py cover penoplast-case --force   # пересобрать

python3 generate_cover.py --slug my-post \
  --title "Заголовок" --subtitle "Подзаголовок"
```

Агент кладёт сгенерированный PNG в `assets/covers/_import/{id}.png` и запускает `generate_cover.py --force`.
