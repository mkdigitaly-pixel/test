11. Без эмодзи в H2 (в отличие от конкурентов)
12. Без фраз из banned-phrases.md

После написания:

## Антипаттерны (из GitHub + практика)

| Плохо | Хорошо |
|-------|--------|
| `mkekspert.ru/razbor-direct?utm_...` голым текстом | `[Бесплатный разбор](https://mkekspert.ru/razbor-direct?...)` |
| `\| таблица \| markdown \|` | список: `— CPL: было X, стало Y` |
| `**жирный**` в надежде на TG→Дзен | жирный в Студии или `<b>` в HTML |
| Один сплошной текст без H2 | H2 каждые 2–3 абзаца |
| Заголовок-кликбейт, капс | конкретика + цифра/боль |
