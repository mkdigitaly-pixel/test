# Разметка Дзен (dzen.ru/klientyandtrafik)

Источники: [справка Дзена — статья](https://dzen.ru/help/ru/channel/article.html), [RSS/HTML](https://dzen.ru/help/ru/website/rss-modify.html), [требования к контенту](https://dzen.ru/help/ru/requirements/content_requirements.html).  
GitHub и промпт: `dzen-github-sources.md`, `dzen-prompt.md`.  
Эталон структуры: [статья Свистушкиной](https://dzen.ru/a/ang5i_6noirlj6-z) (H2, короткие абзацы, **анкорные ссылки**).

Файлы: `articles/dzen/articles/YYYY-MM-DD-slug.md`  
Публикация (по умолчанию `DZEN_PUBLISH_MODE=rss`):

```bash
cd automation && DRY_RUN=false python3 publish.py publish dzen {campaign-id}
```

→ `articles/dzen/html/SLUG.html` + `articles/dzen/feed.xml` → **Студия Дзена** (RSS или вставка HTML).  
Жирный, H2, ссылки с анкором и обложка сохраняются.

**Не использовать** `@zen_sync_bot` для длинных статей: бот не переносит жирный/H2/ссылки; при тексте >1024 символов обложка уходит отдельным постом.

## Заголовок = H1 (отдельно от тела)

| Правило | Значение |
|---------|----------|
| Где в файле | YAML `title` / `h1` + **не дублировать** в теле как `#` (тело начинается с крючка) |
| Лимит | **до 140 символов** (проверяет `publish.py`) |
| Ссылки | **запрещены** в заголовке |
| Стиль | конкретика, боль/вопрос читателя, без кликбейта и капслока |
| Точка в конце | скрипт добавляет `.` если нет `! ? …` |

**Хорошо:** «Реклама в Директе крутится, а заявок нет: что смотрю в кабинете в первую очередь»  
**Плохо:** «ШОК! Яндекс скрывает правду о Директе» (кликбейт, капс)

### RSS + HTML (режим по умолчанию)

`publish.py` конвертирует markdown в HTML (`<h2>`, `<b>`, `<a>`, списки) и пишет:

| Файл | Назначение |
|------|------------|
| `articles/dzen/html/YYYY-MM-DD-slug.html` | Ctrl+A → вставить в редактор Студии |
| `articles/dzen/feed.xml` | RSS с `content:encoded` (подключить в Студии один раз) |

Переменные в `.env`: `DZEN_COVER_BASE_URL` (публичные URL обложек), `DZEN_RSS_FEED_URL`.

**После публикации:** вписать `dzen_url` в `queue/publish-queue.yaml` → тизеры TG/VK.

### Режим sync (только короткие посты ≤1024 зн.)

`DZEN_PUBLISH_MODE=sync` → `TELEGRAM_DZEN_CHANNEL` → `@zen_sync_bot`.  
Без жирного, H2 и кликабельных ссылок. Для экспертных статей **не использовать**.

### Почему не TG для длинных статей

| Проблема | Причина |
|----------|---------|
| Обложка отдельным постом | Подпись к фото ≤1024; длинный текст — отдельным сообщением |
| Нет жирного / H2 | `@zen_sync_bot` не переносит разметку из Telegram |
| Голые URL вместо анкоров | То же — ссылки в Студии вручную |

```bash
cd automation && python3 publish.py format-dzen-html articles/dzen/articles/SLUG.md
```

## Ссылки (кликабельный анкор, не URL в строке)

| Плохо | Хорошо |
|-------|--------|
| `mkekspert.ru/razbor-direct?utm_source=dzen...` | `[Бесплатный разбор Яндекс Директ](https://mkekspert.ru/razbor-direct?utm_source=dzen&utm_medium=article&utm_campaign=slug)` |
| `t.me/mariyaprodirect` | `[Канал в Telegram](https://t.me/mariyaprodirect)` |
| `@Mariya1740` без ссылки | `[@Mariya1740](https://t.me/Mariya1740)` — напишите **РАЗБОР** |

Правила:
- В markdown-исходнике — только `[текст](url)`; голый URL в теле **запрещён**
- Анкор = действие или смысл («Бесплатный разбор», «Канал»), не домен
- UTM остаётся в `href`, читатель его не видит
- В RSS/HTML: `<a href="...">анкор</a>` — whitelist Дзена, переносится автоматически
- В режиме sync: `@zen_sync_bot` не переносит кликабельность → в Студии вручную

Пример CTA (как в [эталоне](https://dzen.ru/a/ang5i_6noirlj6-z), но без эмодзи в заголовках):

```
Если хотите — посмотрю ваш кабинет и сайт.

[Бесплатный разбор Яндекс Директ](https://mkekspert.ru/razbor-direct?utm_source=dzen&utm_medium=article&utm_campaign={utm_campaign})

[Канал в Telegram](https://t.me/mariyaprodirect) — больше кейсов

[@Mariya1740](https://t.me/Mariya1740) — напишите **РАЗБОР**
```

## Структура статьи

```
Крючок (2–4 предложения) — боль, ситуация, обещание пользы

## H2 — смысловой блок (~300–500 знаков)
Абзацы по 2–4 предложения.

### H3 — деталь внутри блока (по необходимости)
Текст, список, цифры.

## H2 — следующий блок
...

## Было / стало (для кейсов)
Таблица или короткий список с цифрами.

## Вывод
3–5 тезисов.

---
CTA: razbor-direct + ссылка на TG
```

### Подзаголовки H2 / H3

- **H2** — каждые 2–3 абзаца (~500 знаков), одна мысль на блок
- **H3** — внутри H2, если блок длинный
- Единообразие: «Что проверить», «Как исправить», «Что делать дальше» (один глагол в начале)
- H2/H3 в markdown (`##`, `###`) → в Дзене дают **оглавление** (кнопка ☰ у читателя)

### Абзацы и списки

- Абзац: 2–4 предложения, пустая строка между абзацами
- Списки: маркированные `—` или нумерованные (в редакторе Дзена — кнопки списка)
- Цифры: конкретные (CPL, %, срок), только из кейсов — не выдумывать
- Объём: **2500–6000 знаков** для экспертных статей (минимум ~1500 для нормальных показов)

## Обложка

| Параметр | Значение |
|----------|----------|
| Минимум | 820×460 px |
| Рекомендуем | 1200×675 или 1920×1080 |
| Текст на обложке | 3–7 слов, крупно, контраст |
| Файл в проекте | `assets/covers/{campaign-id}.jpg` |
| Генерация | Агент (GPT) + бренд-оверлей, см. `references/brand-visual.md` |
| Обязательно | Дзен-статья (фото в TG→Дзен), тизеры TG/VK |

## Frontmatter (шаблон)

```yaml
---
title: "Заголовок для Дзена (H1)"
description: "1–2 предложения для сниппета"
h1: "то же, что title"
main_keyword: "ключевая фраза"
lsi: ["фраза 1", "фраза 2"]
cta_url: "https://mkekspert.ru/razbor-direct"
utm_campaign: "slug-кампании"
platform: dzen
---
```

Тело файла **без** `# H1` — сразу крючок. H1 только в YAML.

## Чеклист перед публикацией

- [ ] `title` ≤ 140 символов, без ссылок
- [ ] H1 не дублируется в теле
- [ ] Есть ≥ 3 блока H2
- [ ] Крючок в первых 2 абзацах
- [ ] Цифры только из реальных кейсов
- [ ] Ссылки — `[анкор](url)`, не голый домен
- [ ] CTA razbor-direct + UTM (в href, не в тексте)
- [ ] Обложка готова
- [ ] Нет фраз из `banned-phrases.md`
- [ ] Голос: `maria-voice.md`

---

## Не делать

- Кликбейт и «обманные» заголовки
- Сплошной текст без H2 (падает дочитываемость)
- Копипаст с VC/TG без адаптации
- SEO-шаблон «в этой статье мы рассмотрим…»
- Капслок, куча восклицательных знаков
