## Как агент использует кейс

1. Открыть URL из таблицы → выписать было/стало, шаги, нишу
2. Создать бриф `briefs/YYYY-MM-DD-{id}.md` с `source_url`
3. Написать статью в `articles/dzen/articles/` — **своя структура H2**, не копия сайта
4. Проверить: нет контактов context-sea, есть UTM, голос Марии
5. Добавить в `queue/publish-queue.yaml`
