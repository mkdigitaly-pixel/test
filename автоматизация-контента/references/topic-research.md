## Алгоритм (агент)

### 1. Сбор тем (раз в 2–4 недели)

| Критерий | Где смотреть |
|----------|--------------|
| Актуальность | статьи 2025–2026, обновления Директа |
| Спрос | частые заголовки на Promopult + Click (ЕПК, Метрика, РСЯ, автостратегии) |
| Вовлечение | Хабр: рейтинг, комментарии, закладки |
| Пробел для нас | B2B, производство, кейсы с цифрами — чего нет у агрегаторов |
| SEO | ключ в title, коммерческий/инфо интент — `plan/dzen-seo-content-plan.md` |

Заносить кандидатов в `plan/topic-sources-backlog.md`.

### 2. Разбор структуры (не текста!)

Для каждой исходной статьи выписать **только скелет**:

```yaml
source_url: ""
source_title: ""
structure:
  - H2: "Что такое …"
  - H2: "Кому подходит"
  - H2: "Как настроить" 
    - H3: "Шаг 1 …"
  - H2: "Ошибки"
  - H2: "Выводы"
intent: info | how-to | case | news
lsi: []
why_interesting: ""  # почему заходит аудитории
```

**Не копировать** формулировки, абзацы, списки из источника.

### 3. Рерайт под Марию Ковaleву

| Правило | Как |
|---------|-----|
| **100% уникальность** | новые предложения, другой порядок блоков, свои примеры |
| Голос | `references/brand.md`, `maria-voice.md` — «я», B2B, цифры |
| Кейсы | `references/case-sources.md` — только наши контакты в CTA |
| Структура | можно взять логику H2, но добавить блок «что делаю на практике» |
| Длина Дзен | 4000–8000 знаков, H2 каждые 300–500 слов — `dzen-markup.md` |
| Запрет | чужие бренды в CTA, копипаст, «мы» без лица |

Проверка уникальности перед публикацией:
- не совпадают цепочки из 8+ слов с источником
- другие заголовки H2 (синонимы, угол B2B)
- есть хотя бы 1 кейс/цифра mkekspert или практический чек-лист

### 4. Типовые структуры (что «дочитывают»)

**How-to (инструмент)** — по образцу Promopult/Click:
1. Боль в заголовке / лиде
2. Что это и зачем B2B
3. Пошаговая настройка (5–7 шагов)
4. Ошибки
5. Когда не подходит
6. CTA razbor-direct

**Диагностика** — по образцу Хабр (высокий практический интерес):
1. Симптом («крутится, заявок нет»)
2. 5–7 проверок в кабинете
3. Что смотрю в Метрике / CRM
4. Быстрые правки
5. CTA

**Кейс** — наша сильная сторона:
1. Ниша + цифры было→стало
2. Исходная ситуация
3. Что меняла (порядок важен)
4. Результат в цифрах
5. Что переносится на другие B2B
6. CTA

**Обзор новинок** — Promopult «новости года»:
1. 5–7 пунктов, каждый — «что значит для B2B»
2. Без пересказа пресс-релиза — только вывод для рекламодателя
3. CTA

### 5. Привязка к очередям

| Тип | Куда |
|-----|------|
| Статья Дзен | `publish-queue.yaml` + `briefs/` + `articles/dzen/articles/` |

| Свой TG | `posts-queue.yaml` + `articles/tg/` |
| Свой VK | `posts-queue.yaml` + `articles/vk/` |

Согласование: `ок <id>` → `approved`.

## Шаблон брифа (перед написанием)

Файл: `briefs/YYYY-MM-DD-{id}.md`

```yaml
---
id: offline-conversions
main_keyword: "офлайн конверсии яндекс директ"
lsi: ["загрузка конверсий", "crm директ", "обучение стратегии"]
intent: how-to
source_structure:
  - url: https://habr.com/ru/articles/1069424/
    take: "H2 про офлайн-конверсии + чек-лист, без кода и антибот-лайфхаков"
pillar: P4
rewrite_angle: "B2B: звонок и заявка в CRM, кейс пенопласт"
cta: razbor-direct
---
```

## Чего не делать

- Копировать абзацы даже с «лёгким» перефразом
- Ссылаться на click.ru / promopult как авторитет в тексте
- Писать про агентства-конкурентов из рейтингов VC/Habr
- Брать темы без B2B-угла (игры, ecom-only) без адаптации
