# SEO-правила для статей Дзена

Краткая выжимка для агента и автора. Полный план: `plan/dzen-seo-content-plan.md`.  
Разметка и H1/H2: `dzen-markup.md`. Бренд: `brand.md`. Запреты: `banned-phrases.md`.

---

## Перед написанием

1. Бриф в `briefs/`: главный ключ, LSI (3–7), интент, гэп vs топ-5 Яндекса
2. Один `id` кампании = одна запись в `queue/publish-queue.yaml`
3. Проверить матрицу в `plan/dzen-seo-content-plan.md` — нет ли дубля темы

---

## Заголовок (title / h1)

| Правило | Значение |
|---------|----------|
| Длина | **70–100 символов** (макс. 140) |
| Ключ | ближе к началу, естественно |
| Кейс | цифра + ниша |
| Гайд | боль или вопрос ЦА |
| Запрет | кликбейт, капс, ссылки в заголовке |

---

## Тело

| Элемент | Требование |
|---------|------------|
| Лид | ответ на запрос в 2–3 предложениях |
| H2 | каждые 300–500 знаков, подзапросы из LSI |
| H3 | детали внутри длинного H2 |
| Ключ | в лиде, 1–2 H2, естественно в тексте |
| Объём | кейс 5000–7000, гайд 3500–5000 знаков |
| FAQ | 3–5 вопросов в конце (НЧ, AEO) |
| CTA | один: razbor-direct + UTM + ссылка на TG |

---

## Интент → тип статьи

| Интент | Структура | Пример id |
|--------|-----------|-----------|
| Диагностика | боль → чек-лист → CTA | `7-errors-direct`, `no-leads-direct` |
| Кейс | было → шаги → стало → вывод | `penoplast-case`, `facade-leads` |
| How-to | задача → шаги → ошибки → CTA | `metrika-goals`, `epk-leads` |
| Коммерция | проблема → критерии → цена/формат | `choose-directologist`, `direct-price` |

## Чеклист перед сдачей

- [ ] Один главный ключ, понятный интент
- [ ] Title/h1 не дублируют друг друга слово в слово
- [ ] H1 только в YAML, не в теле
- [ ] ≥ 3 блока H2
- [ ] Нет нейроштампов (`banned-phrases.md`)
- [ ] Цифры только из реальных кейсов (`brand.md`)
- [ ] CTA razbor-direct с utm_campaign
