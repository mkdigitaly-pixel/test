# Разметка VK (vk.ru/klientyandtrafik)

Источники: [оформление постов VK](https://niksolovov.ru/oformlenie-postov-vk), [первые строки и картинка](https://quasa.io/ru/media/kak-oformit-post-v-kzagolovok-tekst-kartinka).

Файлы: `articles/dzen/teasers/vk/` и `articles/vk/`.  
API публикует **plain text** — жирный через редактор вручную; в исходнике — приёмы ниже.

---

## Лимиты

| Параметр | Значение |
|----------|----------|
| Текст поста | до 15 940 знаков |
| Оптимум | **500–1500** знаков |
| Обложка | 1080×1350 (4:5, вертикаль) — из горизонтальной без обрезки в квадрат |
| Эмодзи | **1–2** на пост (в начале или у CTA) |

## Структура «красивого» поста VK

```
ПЕРВАЯ СТРОКА — тема и боль (как заголовок)

Вторая-третья — для кого и в чём суть. Без длинного вступления.

Что разобрала:
• пункт
• пункт
• пункт

Читать на Дзен:
https://dzen.ru/a/...

Бесплатный разбор рекламы →
mkekspert.ru/razbor-direct

Вопросы — напишите в сообщения сообщества или @Mariya1740
```

### Правила первых строк

1. **Строка 1** = о чём пост (видна в ленте до «Показать полностью»)
2. **Строка 2–3** — условия/для кого (B2B, Директ, ниша)
3. Цену, срок, цифру — не прятать в конец
4. Пустая строка между смысловыми блоками

### Акценты без markdown

| Приём | Пример |
|-------|--------|
| КАПС одной фразы | «Директ запущен, а заявок НЕТ» |
| Кавычки | «Сливаем бюджет на автотаргет» |
| Символ • | списки |
| Эмодзи в начале | 📊 или ⚠️ одно |
| Стрелка → | перед ссылкой CTA |

Не использовать: `[текст](url)`, хештеги ради хештегов, >10 хештегов (не попадут в поиск).

### Хештеги (опционально)

Формат VK: `#тема@klientyandtrafik` — максимум **2–3** штуки, только по делу:
`#яндексдирект@klientyandtrafik` `#контекст@klientyandtrafik`

## Картинка к посту

- Тизеры на Дзен: обложка из `assets/covers/`
- На картинке: 3–7 слов, крупный шрифт, контраст
- Картинка + текст должны вместе объяснять тему (не «рандомная стоковая»)

Автозагрузка: `VK_USER_TOKEN` + `publish.py` (см. `checklists/vk-photo-token.md`).

## Отличия от Telegram

| TG | VK |
|----|-----|
| `**жирный**` → HTML | КАПС / кавычки / первая строка |
| @Mariya1740 | сообщения группы / @Mariya1740 |
| 2–5 эмодзи | 1–2 эмодзи |
| Короче | Чуть длиннее, больше воздуха между абзацами |
| Тире `—` | Буллеты `•` |

---

## Не делать

- Копипаст из TG без переработки
- Markdown-ссылки
- Простыня без пустых строк
- Несколько тем в одном посте
- Рекламный крик («УСПЕЙ», «ТОЛЬКО СЕГОДНЯ»)
