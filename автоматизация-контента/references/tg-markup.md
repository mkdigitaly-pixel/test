# Разметка Telegram (@mariyaprodirect)

**Premium:** длинные посты до 4096 знаков, фото + разметка.  
Файлы: `articles/dzen/teasers/tg/` (тизеры) и `articles/tg/` (свой контент).

---

## Лимиты

| Тип | Лимит |
|-----|-------|
| Текст без фото | **4096** знаков |
| Подпись к фото | **1024** знака |
| Длинный пост + фото | фото отдельно **или** текст ≤1024 под фото; иначе — фото + длинный текст двумя сообщениями |

`publish.py` шлёт фото, если текст ≤1024; при Premium и длинном тексте — сократите тизер или публикуйте без обложки в TG (обложка остаётся в Дзене).

---

## Разметка в исходнике → HTML в Telegram

В `.md` пишем так — бот конвертирует в `parse_mode=HTML`:

| В исходнике | В Telegram |
|-------------|------------|
| `**жирный**` | **жирный** |
| `__курсив__` | _курсив_ |
| `~~зачёркнутый~~` | ~~зачёркнутый~~ |
| `` `код` `` | моноширинный |
| ссылка как URL | кликабельная (без `[текст](url)`) |

**Списки:** тире `—` в начале строки (не нумерация).  
**Эмодзи:** 2–5 на пост, не в каждой строке. Рабочие: 👇 📌 ✅ ⚠️ 💬 📊

## Шаблон: пост канала (`articles/tg/`)

```
**Заголовок-мысль** (первая строка = суть)

Абзац 1 — контекст или история.

Абзац 2 — вывод или инсайт.

— буллет при необходимости
— ещё один

📌 **CTA:** razbor-direct или вопрос в комментарии
```

Типы постов канала (не привязаны к Дзену):
- короткий кейс с цифрами
- чек-лист (5 пунктов)
- «что изменилось в Директе»
- история / сторителлинг (`prompts/day3-storytelling.md`)

## Выделение текста — когда

| Приём | Где |
|-------|-----|
| **Жирный** | крючок, CTA, ключевая цифра |
| _Курсив_ | редко, цитата клиента |
| Эмодзи 👇 | перед ссылкой на Дзен |
| Эмодзи 📌 | перед CTA |

Не выделять всё подряд — 3–6 акцентов на пост.

## Отличия от VK и Дзена

| | TG | VK | Дзен |
|--|----|----|------|
| Длина | средняя | чуть длиннее | длинная статья |
| Списки | `—` | `•` или `—` | H2 + списки |
| Разметка | HTML (**bold**) | plain + CAPS для акцента | H2/H3 в редакторе |
| @упоминание | @Mariya1740 | «напишите в сообщения» | ссылка на TG |

**Один смысл — три разных файла.** Не копипаст.

## Не делать

- Длинные «статьи» в основной канал → в `dzen/articles/`
- Один файл на TG и VK
- Markdown-ссылки `[текст](url)` — только голые URL
- Больше 6 эмодзи на пост
- Нейроштампы → `banned-phrases.md`
