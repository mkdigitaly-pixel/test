# Разметка Telegram (@mariyaprodirect)

Свой контент канала и тизеры на Дзен — **отдельные файлы**.

## Формат

- Короткие абзацы, 1–2 предложения
- Списки через **тире** `—`, не нумерация
- Эмодзи умеренно (1–3 на пост)
- Ссылки явно, без markdown `[текст](url)` — в TG копируете как есть или бот шлёт plain text
- **Жирный** в исходнике `**текст**` — при автопостинге снимается; для ручного поста можно оставить

## Тизер на Дзен (папка `dzen/teasers/tg/`)

```
Крючок — боль одной фразой.

2–3 строки сути.

Куда смотрю / что внутри:
— пункт
— пункт

Читать на Дзен 👇
https://dzen.ru/a/...

Разбор: mkekspert.ru/razbor-direct
@Mariya1740 — РАЗБОР
```

## Пост канала (папка `articles/tg/`)

- Без обязательной ссылки на Дзен
- Кейсы, лайфхаки, новости Директа
- Голос: `references/maria-voice.md`

## Не делать

- Длинные «статьи» в основной канал (они — в `dzen/articles/`)
- Один файл на TG и VK сразу
