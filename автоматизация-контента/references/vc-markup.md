# VC.ru — разметка и публикация

Профиль: [vc.ru/id5544975](https://vc.ru/id5544975)  
UTM: `utm_source=vc` → см. `references/utm.md`

---

## Можно ли постить автоматически?

| Способ | Реальность |
|--------|------------|
| Официальный API для статей | **Нет** — VC не даёт публичный write API |
| `publish.py` | **Нет** — VC не подключён |
| Бот VC для импорта из Telegram | **Да, полуавто** — [vc.ru/about-tg-bot](https://vc.ru/about-tg-bot): посты из TG-канала дублируются в блог VC (бета, по заявке на telegram@vc.ru) |
| Selenium / скрипты | Технически возможно, но хрупко (EditorJS, авторизация) — **не рекомендуем** |
| Ручная вставка | **2–3 мин** — основной рабочий процесс |

**Вывод:** полной автоматизации как у VK/TG **нет**. Оптимально: агент готовит текст → вы вставляете в редактор VC → публикуете. Либо подключаете TG→VC бот для дублирования **коротких** постов канала (не длинных статей Дзена).

## Формат статьи на VC (EditorJS)

VC хранит статью блоками. В markdown-исходнике закладываем структуру:

```
# H1 — заголовок статьи (интрига + польза)

Лид: 2–4 предложения. Кто, что, зачем читать.

## Подзаголовок
Абзац. Короткие предложения.

## Кейс / цифры
• было: …
• стало: …

## Вывод
Тезисы.

---
CTA: mkekspert.ru/razbor-direct?utm_source=vc&utm_medium=article&utm_campaign=…
```

### Отличия от Дзена

| | VC.ru | Дзен |
|--|-------|------|
| Аудитория | предприниматели, маркетинг, IT | шире, алгоритмическая лента |
| Тон | чуть более «деловой», можно цифры в заголовке | разговорный, как на разборе |
| Длина | 3000–8000 знаков норм | 2500–6000 |
| Картинки | вставляются в редакторе | обложка + в тексте |
| Модерация | редакция / подсайт | алгоритмы Дзена |

## Workflow для mkekspert

### Вариант A — статья сначала на VC (как кейс пенопласт)

1. Агент пишет/правит в `content/vc-*.md` или `articles/vc/`
2. 👤 Вы публикуете на VC вручную
3. Агент адаптирует в `articles/dzen/articles/` (без копипаста 1:1)
4. Дзен → тизеры TG/VK по очереди

### Вариант B — статья сначала на Дзен

1. Публикуем в Дзен через синхробот
2. На VC — **сокращённая версия** или «мнение + цифры кейса» (уникальный текст)
3. Не дублировать слово в слово (SEO и модерация)

### Вариант C — TG → VC бот

1. Подаёте заявку на telegram@vc.ru (канал @mariyaprodirect + блог VC)
2. Короткие посты канала автоматом появляются на VC
3. **Не подходит** для длинных статей Дзена и материалов с пометкой «реклама»
