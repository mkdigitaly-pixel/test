# AGENTS.md — mkdigitaly / test

Инструкции для **OpenAI Codex** (и совместимых агентов) в этом репозитории.

## Что это за репо

Два независимых контура:

| Папка | Назначение |
|-------|------------|
| `автоматизация-контента/` | Контент и SEO mkekspert.ru / blog.mkekspert.ru / Дзен / TG / VK |
| `parser/` | Парсеры номенклатуры по сайтам-поставщикам |

Корневой `.cursor` → симлинк на `parser/.cursor`. Правила Cursor для контента лежат в `автоматизация-контента/.cursor/rules/`.

## Как работать

1. Определи контур задачи и читай вложенный `AGENTS.md` в этой папке.
2. Не коммить секреты: `**/ДОСТУПЫ.env`, `.env`, ключи API.
3. Не трогай `work/nomenclature_parser/` без явной просьбы (локальный черновик).
4. Коммиты и PR — только по запросу пользователя; сообщения коммитов — по делу.
5. Предпочитай правки существующих файлов новым; не плоди markdown «просто так».

## Codex + Cursor

- **Codex** читает `AGENTS.md` (этот файл и вложенные).
- **Cursor** читает `.cursor/rules/*.mdc` и skills.
- Дублируй критичные правила в оба места только если они реально нужны обоим; иначе сошлись на первоисточник.

## Code Review Rules

- Не предлагай Publish в Tilda без явного «да» пользователя.
- Не коммить и не печатай содержимое `ДОСТУПЫ.env` / `.env`.
- Для парсеров: не выдумывай поля товаров; пустое лучше фейка.
- Для контента Дзен: ссылки только markdown `[текст](url)`, без голых доменов в теле.
