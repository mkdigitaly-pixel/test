# AGENTS.md — parser

Парсеры номенклатуры по сайтам поставщиков.

## Структура

- Один сайт = одна папка внутри `parser/` (имя по домену/бренду).
- Общие правила — в `.cursor/rules/*.mdc`; специфика сайта — в папке проекта (README/конфиг).
- Корневой `/opt/work/.cursor` → симлинк на `parser/.cursor`.

## Перед кодом

1. Разбери каталог, карточки, пагинацию, PDF/прайсы.
2. Структуру категорий и поля бери с сайта — не выдумывай.
3. Из PDF вытаскивай конкретные модели/типоразмеры из таблиц, не одну строку на серию.
4. Нет поля на сайте → оставь пустым.

## Вывод

TSV (таб), эталон как `raytechi_prochee.tsv`:

`Модель	Наименование	Категория	Цена	Артикул	Ссылка на товар	Источник`

Со строкой-заголовком группы перед товарами. Дополнительно можно `.xlsx`.

## Этика

Разумные паузы, нормальный User-Agent, без агрессивного обхода.

## Code Review Rules

- Не смешивай данные разных сайтов в одной папке.
- Не подставляй выдуманные артикулы/цены/модели.
