# Перевод номенклатуры на русский

## Когда применять
- После сбора EN-каталога (TCI и др.) в `data/nomenclature.tsv` / `data/cat_*.tsv`
- По запросу: «переведи», «на русский», «русифицируй номенклатуру»

## Вход / выход
- **Вход**: TSV с колонками `Модель | Наименование | Категория | Цена | Артикул | Ссылка на товар | Источник`
- **Выход**: тот же TSV (или `nomenclature_ru.tsv`), поля **Наименование** и **Категория** (и заголовки групп) на русском
- **Не трогать**: Модель (CAS), Артикул, Ссылка, Источник, **Цена** (уже рубли без НДС, цифры — не трогать)

Читай также правила: `parser/.cursor/rules/nomenclature.mdc`.

## Алгоритм
1. Открыть целевой TSV.
2. Для каждой строки-группы (заполнено только первое поле) — перевести путь категории.
3. Для каждой товарной строки — перевести **Наименование** и **Категория**.
4. Сохранить UTF-8 TSV (таб), без лишних кавычек/переносов внутри ячеек.
5. Кратко отчитаться: сколько строк переведено, путь к файлу.

Обрабатывать **батчами** (например по 1 категории / до ~50–80 строк за проход), не ломая порядок сайта.

## Наименование (химия / реактивы TCI)
- Ед.ч.; формулировка как у химического названия, не «маркетинговый» перевод.
- **Начинать с существительного** (типа соединения), дальше уточнения: эфир / пропионат / сульфонат / кислота / … — не с родительного падежа кислоты.
  - Плохо: `Уксусной кислоты … эфир`
  - Хорошо: `Эфир уксусной кислоты …`
- Сохранять стереохимию и служебные символы: `(R)`, `(S)`, `(+)`, `(-)`, `tert-`, номера положений, скобки.
- Корни/суффиксы по русской хим. номенклатуре: phenyl→фенил, oxazolidinone→оксазолидинон, camphorsultam→камфорсультам, sulfinamide→сульфинамид, thione→тион, carboxamide→карбоксамид, ester→эфир, acid→кислота и т.п.
- Уточнения в `[...]` переводить со **строчной**: `[Reagent for ...]` → `[реагент для ...]`.
- Не вставлять в наименование артикул/CAS/бренд TCI.
- Не выдумывать свойства, которых нет в EN-названии.
- Если уверенный русский эквивалент неизвестен — оставить спорный фрагмент латиницей и пометить в отчёте, не «угадывать» радикально.

Примеры:
| EN | RU |
|----|----|
| `(R)-(-)-4-Phenyl-2-oxazolidinone` | `(R)-(-)-4-Фенил-2-оксазолидинон` |
| `(S)-(-)-tert-Butylsulfinamide` | `(S)-(-)-трет-Бутилсульфинамид` |
| `(-)-10,2-Camphorsultam` | `(-)-10,2-Камфорсультам` |
| `Acetic Acid … Ester [Reagent for double aldol reaction]` | `Эфир уксусной кислоты … [реагент для двойной альдольной реакции]` |
| `… Propionate [Reagent for …]` | `Пропионат … [реагент для …]` |

Для **оборудования** (не химия) — классические правила nomenclature.mdc: начать с существительного («Конвейер …»).

## Категория
- Переводить каждый сегмент пути `A/B/C` → `А/Б/В`.
- Существительное в начале сегмента где уместно; согласовать ед./мн. с типом.
- Типовые TCI:
  - Chemistry → Химия
  - Materials Science → Материаловедение
  - Life Science → Науки о жизни
  - Analytical Chemistry → Аналитическая химия
  - Chemicals by Class → Химические соединения по классам
  - Glycoscience → Гликонаука
  - Chiral Auxiliaries → Хиральные вспомогательные вещества
  - Chiral Building Blocks → Хиральные строительные блоки
  - Asymmetric Synthesis → Асимметричный синтез
  - Synthetic Reagents → Синтетические реагенты

Строка-группа перед товарами = тот же русский путь категории.

## Запрещено
- Машинный «кривой» перевод стереохимии (не писать «(R)-минус-…» вместо `(R)-(-)-…`)
- Менять порядок строк / сортировать по алфавиту
- Подставлять цены или выдуманные CAS
- Переводить URL и коды товаров
